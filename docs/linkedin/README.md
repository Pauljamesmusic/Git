# LinkedIn assets

Rendered at 2x. Every screenshot is the real running app — nothing is redrawn
or faked — captured with the actual Bricolage Grotesque / Instrument Sans /
JetBrains Mono webfonts rather than system fallbacks.

| File | Size | Use |
| --- | --- | --- |
| `prompt-vault-portrait-1200x1500.png` | 2400×3000 | **Post this one.** 4:5 takes the most feed space on LinkedIn. |
| `prompt-vault-square-1200x1200.png` | 2400×2400 | Carousel slide, or a second image. |
| `prompt-vault-landscape-1200x630.png` | 2400×1260 | Link preview / featured section / banner. |
| `raw-*.png` | — | Unframed screenshots, if you want to lay out your own. |

Regenerate: `node capture.mjs` then `node render.mjs` against `compose.html`.
